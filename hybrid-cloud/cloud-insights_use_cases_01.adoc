Con la instalación y configuración de Cloud Insights para supervisar su solución de centro de datos de FlexPod, podemos explorar algunas de las tareas que puede realizar en la consola para evaluar y supervisar su entorno. En esta sección, se destacan cinco casos de uso principales para Cloud Insights:

* Integración de Digital Advisor
* Exploración de paneles en tiempo real
* Creación de paneles personalizados
* Resolución avanzada de problemas
* Optimización del almacenamiento




[[digital-advisor-integration]]
== Integración de Digital Advisor

Cloud Insights está totalmente integrado en la plataforma de supervisión de almacenamiento Digital Advisor. Un sistema ONTAP, implementado como parte de una solución FlexPod Datacenter, se configura automáticamente para enviar información a NetApp a través de la función AutoSupport, que viene integrada en cada sistema. Estos informes se generan de forma programada o de manera dinámica cada vez que se detecta un fallo en el sistema. Los datos comunicados a través de AutoSupport se agregan y se muestran en paneles de control de fácil acceso dentro del menú Digital Advisor en Cloud Insights.

. Filtro para el recopilador de datos específico de su entorno. En este ejemplo, vamos a filtrar por el término FlexPod.

image:cloud-insights_image23.png["Una captura de pantalla que muestra la página de recopiladores de datos filtrada por FlexPod Datacenter"]

image:cloud-insights_image24.png["Una captura de pantalla del resumen del recopilador de datos de FlexPod Datacenter con la cronología de eventos y el dispositivo de almacenamiento reportado"]

En la lista de dispositivos situada cerca de la parte inferior, haga clic en el nombre del sistema de almacenamiento de ONTAP que se va a supervisar. Esto muestra un tablero de información recopilada sobre el sistema, incluidos los siguientes detalles:

Además, en esta página, en la sección de Políticas de rendimiento, puedes encontrar un enlace a NetApp Digital Advisor.

[[explore-real-time-dashboards]]
=== Explore los paneles en tiempo real

Cloud Insights puede mostrar consolas en tiempo real de la información que se obtuvo en el sondeo del sistema de almacenamiento de ONTAP implementado en una solución para centros de datos de FlexPod. La unidad de adquisición de Cloud Insights recopila datos a intervalos regulares y rellena el panel del sistema de almacenamiento predeterminado con la información recopilada.



==== Acceda a gráficos en tiempo real a través de la consola de Cloud Insights

Desde el panel del sistema de almacenamiento, puede ver la última vez que el recopilador de datos actualizó la información. Un ejemplo de esto se muestra en la siguiente figura.

image:cloud-insights_image28.png["Una captura de pantalla de los detalles del recopilador de datos de Cloud Insights que muestra una adquisición exitosa hace 3 minutos, a la 1:21 p. m."]

De forma predeterminada, la consola del sistema de almacenamiento muestra varios gráficos interactivos donde se muestran métricas en todo el sistema desde el sistema de almacenamiento en el que se está sondeando o desde cada nodo individual, incluidos: Latencia, IOPS y rendimiento, en la sección Expert View. En la siguiente figura se muestran ejemplos de estos gráficos predeterminados.

image:cloud-insights_image29.png["Una captura de pantalla de Cloud Insights Expert View con gráficos de latencia, IOPS y rendimiento, así como detalles de los recursos"]

De forma predeterminada, los gráficos muestran información de las últimas tres horas, pero puede establecerlos en un número de valores distintos o en un valor personalizado de la lista desplegable, situada cerca de la parte superior derecha del panel del sistema de almacenamiento. Esto se muestra en la siguiente figura.

image:cloud-insights_image30.png["Una captura de pantalla del panel de control de almacenamiento con el menú desplegable de intervalos de tiempo que muestra desde Últimos 15 minutos hasta Personalizado"]



[[create-custom-dashboards]]
=== Crear paneles personalizados

Además de utilizar las consolas predeterminadas que muestran información de todo el sistema, puede usar Cloud Insights para crear consolas totalmente personalizadas que le permitirán centrarse en el uso de recursos para volúmenes de almacenamiento específicos de la solución para centros de datos de FlexPod, y, por lo tanto, las aplicaciones puestas en marcha en la infraestructura convergente que dependen de dichos volúmenes para que se ejecuten de forma efectiva. De esta forma, puede ayudarle a crear una mejor visualización de aplicaciones específicas y los recursos que consumen en el entorno del centro de datos.



==== Cree un panel personalizado para evaluar los recursos de almacenamiento

Para crear una consola personalizada para evaluar los recursos de almacenamiento, complete los siguientes pasos:

. Para crear un panel personalizado, pase el ratón sobre Paneles en el menú principal de Cloud Insights y haga clic en + Nuevo panel en la lista desplegable.
+
image:cloud-insights_image31.png["Una captura de pantalla del menú «Cloud Insights Dashboards» con la opción «+ New Dashboard» resaltada"]

+
Se abrirá la ventana Nueva consola.

. Asigne un nombre al panel y seleccione el tipo de widget utilizado para mostrar los datos. Puede seleccionar entre varios tipos de gráficos, incluso notas o tipos de tablas para presentar los datos recopilados.
+
image:cloud-insights_image32.png["Una captura de pantalla de los mosaicos de selección de tipos de widgets del New Dashboard, que incluyen gráficos, indicadores, notas y tablas"]

. Elija variables personalizadas en el menú Agregar variable.
+
Esto permite que los datos presentados se centren en mostrar factores más específicos o especializados.

+
image:cloud-insights_image33.png["Una captura de pantalla que muestra el menú Add Variable con un campo de búsqueda y una lista de variables en un nuevo panel de control"]

. Para crear una consola personalizada, seleccione el tipo de widget que desea utilizar, por ejemplo, un gráfico circular para mostrar la utilización del almacenamiento por volumen:
+
.. Seleccione el widget Gráfico circular de la lista desplegable Agregar widget.
.. Asigne un nombre al widget con un identificador descriptivo, como `Capacity Used`.
.. Seleccione el objeto que desea mostrar. Por ejemplo, puede buscar según el término clave volume y seleccionar `volume.performance.capacity.used`.
.. Para filtrar por sistemas de almacenamiento, utilice el filtro y el tipo en el nombre del sistema de almacenamiento en la solución de centro de datos FlexPod.
.. Personalice la información que se mostrará. De forma predeterminada, esta selección muestra los volúmenes de datos ONTAP y enumera los 10 primeros.
.. Para guardar el panel personalizado, haga clic en Guardar.
+
image:cloud-insights_image34.png["Una captura de pantalla que muestra un widget de gráfico circular de Capacidad utilizada configurado para la capacidad utilizada del volumen de almacenamiento"]

+
Después de guardar el widget personalizado, el explorador vuelve a la página New Dashboard donde se muestra el widget recién creado y permite realizar acciones interactivas, como modificar el período de sondeo de datos.

+
image:cloud-insights_image35.png["Una captura de pantalla que muestra un panel de control de Cloud Insights con un widget de gráfico circular de Capacidad utilizada"]







[[advanced-troubleshooting]]
=== Resolución avanzada de problemas

Cloud Insights permite aplicar métodos avanzados de resolución de problemas a cualquier entorno de almacenamiento en una infraestructura convergente de FlexPod Datacenter. Usando los componentes de cada una de las funciones mencionadas arriba: integración con Digital Advisor, paneles predeterminados con estadísticas en tiempo real y paneles personalizados, los problemas que puedan surgir se detectan temprano y se resuelven rápidamente. Usando la lista de riesgos en Digital Advisor, un cliente puede encontrar errores de configuración reportados que podrían causar problemas, así como bugs reportados y versiones parcheadas del código que pueden solucionarlos. Observar los paneles en tiempo real en la página principal de Cloud Insights puede ayudar a descubrir patrones en el rendimiento del sistema que podrían ser un indicador temprano de un problema en aumento y ayudar a resolverlo rápidamente. Por último, poder crear paneles personalizados permite a los clientes enfocarse en los activos más importantes de su infraestructura y monitorearlos directamente para asegurarse de que puedan cumplir sus objetivos de continuidad del negocio.



[[storage-optimization]]
=== Optimización del almacenamiento

Además de la resolución de problemas, es posible utilizar los datos recopilados por Cloud Insights para optimizar el sistema de almacenamiento ONTAP implementado en una solución de infraestructura convergente FlexPod Datacenter. Si un volumen presenta una latencia elevada, tal vez porque varias máquinas virtuales con demandas de alto rendimiento comparten el mismo datastore, esa información se muestra en el panel de Cloud Insights. Con esta información, un administrador de almacenamiento puede elegir migrar una o más máquinas virtuales a otros volúmenes, migrar volúmenes de almacenamiento entre niveles de agregados o entre nodos en el sistema de almacenamiento ONTAP, lo que da como resultado un entorno con el rendimiento optimizado. La información obtenida de la integración de Digital Advisor con Cloud Insights puede resaltar problemas de configuración que llevan a un rendimiento inferior al esperado y proporcionar la acción correctiva recomendada que, si se implementa, puede solucionar cualquier problema y asegurar un sistema de almacenamiento ajustado de forma óptima.
