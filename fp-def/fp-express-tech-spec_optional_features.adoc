En esta sección se describen las funciones opcionales de FlexPod Express.


NOTE: El arranque SAN es opcional, pero se recomienda encarecidamente, ya que permite trasladar el perfil del servidor durante las actualizaciones o reemplazos de hardware.



[[iscsi-boot-option]]
== Opción de arranque iSCSI

Los requisitos mínimos para la opción de arranque iSCSI incluyen:

* Una función o licencia de iSCSI activada en la controladora de almacenamiento de NetApp
* Un adaptador Ethernet de dos puertos 10 Gbps en cada nodo del par de alta disponibilidad de la controladora de almacenamiento de NetApp
* Un adaptador en el servidor Cisco UCS que sea capaz de arrancar iSCSI




[[cisco-ucs-x-series-direct-and-direct-attached-aff-asa-fas-option]]
== Opción de Cisco UCS X-Series Direct y conexión directa a AFF/ASA/FAS

Los controladores de almacenamiento NetApp pueden conectarse directamente a las interconexiones de estructura Cisco UCS sin ningún conmutador SAN ascendente. FlexPod Express admite tanto el arranque por FC como por iSCSI con UCS X-Series Direct.

Los requisitos de licencia y hardware son los siguientes:

* Se requiere una licencia de protocolo en la controladora de almacenamiento de NetApp.
* Se requiere un adaptador Cisco UCS (iniciador) en el servidor. Para consultar la lista de adaptadores Cisco UCS compatibles, consulta NetApp https://imt.netapp.com["IMT"^].
* Se requiere un adaptador de destino en la controladora de almacenamiento de NetApp.


La siguiente figura muestra una topología de UCS X-Series Direct y ASA de conexión directa para una SAN basada en IP.

image:fp-express-tech-spec_image10.png["Topología ASA de conexión directa y conexión directa de UCS X-Series para SAN basada en IP"]

*Notas:*

* Cisco UCS se configura en el modo de conmutación Ethernet.
* Los puertos iSCSI del destino a las interconexiones de estructura se configuran como puertos de almacenamiento Ethernet para datos iSCSI.


La siguiente figura muestra una topología de UCS X-Series Direct y ASA de conexión directa para redes SAN basadas en IP y en FC.

image:fp-express-tech-spec_image11.png["Topología UCS X-Series Direct y ASA de conexión directa para SAN basadas en IP y FC"]

*Notas:*

* Cisco UCS se configura en modo de conmutación FC.
* Los puertos FC del destino a las interconexiones de estructura se configuran como puertos de almacenamiento FC.


Para obtener más información sobre esta configuración, consulta https://www.netapp.com/pdf.html?item=/media/135828-flexpod-san-ucs-xdirect-asa-nva-deploy-guide.pdf["FlexPod Solución SAN con Cisco UCS X-Series Direct y NetApp ASA"^].


NOTE: En los ejemplos anteriores se utiliza el controlador de almacenamiento ASA de NetApp, pero la misma configuración es compatible con los controladores de almacenamiento AFF y FAS de NetApp.
