= Reglas de FlexPod
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
El diseño de FlexPod admite una arquitectura de infraestructura flexible que abarca una variedad de componentes de hardware y versiones de software.

Usa los conjuntos de reglas como guía para crear o armar una configuración válida de FlexPod. Los números y reglas que aparecen en este documento representan los requisitos mínimos para FlexPod y pueden ampliarse usando productos compatibles dentro de las familias de productos incluidas, según lo que necesites para diferentes entornos y casos de uso.
