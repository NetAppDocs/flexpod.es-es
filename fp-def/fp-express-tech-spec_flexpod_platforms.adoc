= Plataformas FlexPod
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Existen dos plataformas FlexPod:

* *FlexPod Datacenter.* Esta plataforma es una infraestructura de centro de datos altamente escalable, ideal para cargas de trabajo y aplicaciones empresariales, virtualización, IA/ML, bases de datos, SAP HANA, VDI y nube pública y privada. FlexPod Datacenter tiene sus propias especificaciones, que están documentadas en https://docs.netapp.com/us-en/flexpod/fp-def/dc-tech-spec_solution_overview.html["Especificaciones técnicas de FlexPod Datacenter"^].
* *FlexPod Express.* esta plataforma es una infraestructura convergente compacta que está destinada a casos de uso de oficinas remotas y periféricos.


Este documento proporciona las especificaciones técnicas de la plataforma FlexPod Express.
