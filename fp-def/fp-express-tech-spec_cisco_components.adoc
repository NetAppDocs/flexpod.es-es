[[cisco-ucs-x-series-direct]]
== Cisco UCS X-Series Direct

Cisco UCS X-Series Direct es una nueva arquitectura que integra un par de Cisco UCS Fabric Interconnect 9108 100G con Cisco UCS X9508 Chassis y Cisco UCS X-Series Compute nodes para ofrecer la solución UCS X-Series Direct.

Para obtener una visión general rápida de las capacidades y características de la serie X de Cisco UCS, consulta link:https://www.cisco.com/c/en/us/products/collateral/servers-unified-computing/ucs-x-series-modular-system/ucs-x-series-direct-aag.html["Cisco UCS X-Series Direct de un vistazo"^].

Cisco UCS X-Series Direct consta de los siguientes componentes:

* Cisco UCS 9108 100G Fabric Interconnect
* Chasis Cisco UCS X9508
* Nodos de cómputo Cisco UCS X-Series
* Componentes opcionales:
+
** Nodos PCIe y módulo X-Fabric
** Segundo chasis Cisco UCS X9508 con nodos de cómputo X-Series, módulos Intelligent Fabric Cisco UCS 9108-100G y hasta cuatro servidores en rack C-Series





NOTE: Consulta este enlace para ver las especificaciones técnicas completas de UCS X-Series Direct: https://www.cisco.com/c/en/us/products/collateral/servers-unified-computing/ucs-x-series-modular-system/ucs-x-series-direct-ds.html["Ficha técnica de Cisco UCS X-Series Direct"].

[[cisco-unified-edge]]
== Cisco Unified Edge

Cisco Unified Edge es un sistema preparado para la IA que redefine la informática en el perímetro al integrar recursos de computación, redes, almacenamiento y seguridad. El diseño modular está preparado para el futuro, es eficiente en el consumo de energía y fácil de mantener, y puede adaptarse para soportar las cargas de trabajo y los casos de uso actuales, mientras sigue siendo flexible ante el panorama de la IA en rápida evolución.

Para obtener una visión general rápida de las capacidades y funciones de Cisco Unified Edge, consulta link:https://www.cisco.com/c/en/us/products/collateral/servers-unified-computing/unified-edge/unified-edge-at-a-glance.html["Cisco Unified Edge de un vistazo."^]

Cisco Unified Edge se compone de los siguientes componentes:

* Chasis Cisco UCS XE9305
* Dos controladores Cisco Unified Edge Management con switches de 25G integrados
* Nodos de cómputo: opciones de
+
** Nodo de computación Cisco UCS XE130c M8
** Nodo de computación Cisco UCS XE150c M8
