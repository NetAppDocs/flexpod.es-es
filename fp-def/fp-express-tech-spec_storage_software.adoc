FlexPod Express es compatible con los sistemas de almacenamiento que ejecutan el sistema operativo NetApp ONTAP.



== ONTAP de NetApp

El software NetApp ONTAP es el sistema operativo que se ejecuta en los sistemas de almacenamiento AFF, ASA y FAS. ONTAP proporciona una arquitectura de almacenamiento altamente escalable que permite operaciones sin interrupciones, actualizaciones sin interrupciones y una infraestructura de datos ágil.

Para obtener más información acerca de ONTAP, consulte http://www.netapp.com/us/products/platform-os/ontap/index.aspx["Página de productos ONTAP"^].
