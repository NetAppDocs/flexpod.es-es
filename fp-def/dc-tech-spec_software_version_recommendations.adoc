= Recomendaciones sobre la versión del software
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./../media/


[role="lead"]
Una configuración de FlexPod tiene las siguientes recomendaciones de versiones de software:

* Versión de ONTAP: se recomienda la última versión de ONTAP para todas las configuraciones de FlexPod Datacenter. Consulta link:https://docs.netapp.com/us-en/ontap/release-notes/index.html["Notas de la versión de ONTAP"^] para la última versión de ONTAP.
* Versión de Cisco NX-OS: para conocer las recomendaciones generales sobre la versión de Cisco NX-OS para los conmutadores de la serie 9000 de Cisco, consulta link:https://www.cisco.com/c/en/us/td/docs/switches/datacenter/nexus9000/sw/recommended_release/b_Minimum_and_Recommended_Cisco_NX-OS_Releases_for_Cisco_Nexus_9000_Series_Switches.html["Versiones recomendadas de Cisco NX-OS para los switches Cisco Nexus 9000 Series"^].
* Versión del firmware de Cisco UCS:
+
** Consulta este enlace para ver las últimas versiones de link:https://www.cisco.com/c/en/us/support/servers-unified-computing/intersight/products-release-notes-list.html["Infraestructura en modo gestionado de Cisco Intersight y firmware de servidor, firmware de chasis y firmware de nodo PCIe"^].
** Consulta este enlace para ver las últimas versiones de link:https://intersight.com/help/saas/supported_systems/Intersight_Standalone_Mode["Modo autónomo de Cisco Intersight y firmware de CIMC"^].





NOTE: Todos los componentes de software deben figurar y ser compatibles en https://imt.netapp.com["IMT de NetApp"^], todos los componentes de hardware de NetApp y las versiones de ONTAP deben figurar y ser compatibles en https://hwu.netapp.com/Home/Index["Hardware Universe de NetApp"^] y todos los componentes de hardware de Cisco deben figurar y ser compatibles en https://ucshcltool.cloudapps.cisco.com/public/["Cisco HCL"^].
