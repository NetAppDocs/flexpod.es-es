== Requisitos de software para FlexPod Express con NetApp AFF o FAS

Los requisitos de software para el FlexPod Express con NetApp FAS incluyen:

* ONTAP 9.1 o posterior
* Cisco NX-OS versión 7.0(3)I6(1) o posterior
* En la configuración gestionada por Cisco UCS, Cisco UCS Manager UCS 4.0(1b)


Todo el software debe figurar en la lista y ser compatible en el http://mysupport.netapp.com/matrix["IMT de NetApp"^]. Es posible que algunas funciones del software requieran versiones de código más recientes que los requisitos mínimos indicados en las arquitecturas anteriores.
