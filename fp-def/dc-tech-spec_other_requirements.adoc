= Otros requisitos
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Los requisitos adicionales para FlexPod Datacenter incluyen lo siguiente:

* Si planeas usar VMware ESXi como hipervisor, consulta la link:https://compatibilityguide.broadcom.com/["Guía de compatibilidad de Broadcom"] para verificar que tus componentes de hardware y software sean compatibles.
* Para una implementación basada en OpenShift, asegúrate de tener los componentes de hardware y software necesarios que sean compatibles con OpenShift. Consulta el link:https://catalog.redhat.com/en/search["Catálogo de OpenShift"] para más información.
